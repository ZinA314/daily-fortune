# 오늘의 운세 — 사주 × 타로 🔮

생년월일로 만세력(사주 명식)을 세우고, 타로 카드 한 장을 뽑아 오늘의 운세를 확인하는 Next.js 웹 앱입니다.

## 기능

- **만세력 계산** — 생년월일(양력)로 년주·월주·일주를 계산해 한자와 오행(목·화·토·금·수)으로 표시
- **타로 카드 뽑기** — 메이저 아르카나 22장 중 6장이 펼쳐지고, 탭하면 3D 플립 애니메이션과 함께 공개
- **사주 반영 운세** — 나의 일간 오행과 오늘 일진 오행의 관계(비견·인성·식상·재성·관성)에 뽑은 카드의 기운을 조합해 점수·총운·애정운·재물운·직장운 생성 (시드 기반: 같은 날 같은 카드는 항상 같은 결과)
- **오늘의 행운** — 행운의 아이템·색·숫자·시간·방향·일진
- 애플 스타일 UI, 프리텐다드 서체, 다크 모드 및 모바일 반응형 지원

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 구조

- `lib/saju.js` — 만세력(60갑자) 계산: 율리우스 적일 기반 일주, 입춘·절기 근사 경계
- `lib/tarot.js` — 메이저 아르카나 22장 데이터, 행운 아이템/색 목록
- `lib/fortune.js` — 사주 × 일진 × 타로 조합 운세 생성기 (mulberry32 시드 난수)
- `app/page.jsx` — 메인 UI (생년월일 입력 → 만세력 → 카드 선택 → 결과)

> 절기 경계는 근사값을 사용하며, 운세는 재미로 봐주세요 ✨
